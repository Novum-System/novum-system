# NOVUM SYSTEM

Sitio web corporativo de **NOVUM SYSTEM**, desarrollado con Astro y TypeScript.

Actualmente el proyecto se encuentra en etapa de desarrollo frontend, enfocado en la creación de páginas web modernas, profesionales, responsive y optimizadas para SEO.

## 🚀 Tecnologías

- Astro
- TypeScript
- HTML5
- CSS3
- Git
- GitHub
